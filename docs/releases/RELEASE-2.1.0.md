# 2.1 — À deux · préparation locale

Le partage commencé après la 2.0 est complété par un parcours dans l’application : tiroirs, aperçu intégral, envoi/réception explicites, notes attribuées, copie par changement à approuver, carte et glossaire. Les packs restent disponibles (F2.1-01 à F2.1-09, D64).

Les contrôles ajoutés refusent les chemins ou manifestes invalides, les symlinks, un aperçu périmé et le push de commits locaux antérieurs non publiés. Les fichiers Git hors sélection sont exclus du commit et restent locaux. Un partage indisponible laisse les résultats personnels utilisables avec un état explicite.

Voir [le guide](../guide/partager-a-deux.md) et [la spec](../dev/specs/2026-10-11-2.1-partage.md). Les tests se font dans des cerveaux et dépôts fictifs. Cette note décrit le travail local ; elle n’annonce ni tag, ni publication, ni porte d’usage franchie. Les droits GitHub et l’autorisation de l’entreprise restent à confirmer dans le contexte réel.
