# 3.0 — Installable, préparation locale

11 octobre 2026. Code de développement ; aucune version publiée ni porte
d’usage franchie.

F3.0-01 à F3.0-05 : coque Electron sur la même application, runtime embarqué,
premier lancement par activité avec premier projet, parcours sans IA,
sélecteur natif de dossier, diagnostic, sauvegarde et export complet vérifié.
L’icône reprend la marque Atelier existante.

F3.0-06 : configuration de builds Mac et Windows, canaux HTTPS fixes,
contrôle de l’identité de signature, téléchargement et installation explicites.
La commande de release exige une signature et les parcours de test. Le
prototype ne reçoit pas de mise à jour.

F3.0-07 : composants nommés, clavier et focus de panneau testés, zoom natif.
Le contrôle visuel, lecteur d’écran et contrastes réels reste à vérifier.

Un prototype Mac non signé a été construit. Signature, notarisation, exécution
Windows et mise à jour de bout en bout nécessitent leurs validations propres.
Les essais des trois proches pendant deux semaines ne sont pas remplacés par
les tests. Voir la [spec](../dev/specs/2026-10-11-3.0-desktop.md) et le
[guide](../guide/application-desktop.md).
Le [bilan de validation](../dev/VALIDATION-2.1-3.0.md) garde les résultats
mesurés et les contrôles encore ouverts.
