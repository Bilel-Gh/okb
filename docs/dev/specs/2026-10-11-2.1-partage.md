# 2.1 — À deux (D64)

Statut : implémentation locale à vérifier avec les contrôles de publication ; aucune version publiée, porte d’usage en attente.

La 2.1 achève le travail commencé sur le socle 2.0. Un dossier commun, séparé des cerveaux personnels, contient un tiroir par personne. Markdown demeure le savoir ; SQLite conserve la sélection à partager. Le dépôt commun est une copie locale du GitHub autorisé par les personnes, jamais le dépôt Git d’un cerveau personnel.

## Contrats et confidentialité

`share.*` est réservé à la personne ; `shared.*` expose la lecture et la préparation de proposition aux agents. Tous passent par le moteur, avec les mêmes règles dans la CLI, le MCP et l’application. Les notes verrouillées, privées, de carrière, le bagage et les cerveaux confidentiels sont retenus. Le contenu final est inspecté pour détecter des secrets. Les chemins, manifestes et liens symboliques entrants sont contrôlés avant lecture.

Un aperçu périmé fait refuser l’envoi. Le staging et le commit Git utilisent uniquement les fichiers contrôlés et montrés ; les autres fichiers déjà indexés restent locaux. Un historique local déjà en avance fait refuser le push : OKB ne publie pas silencieusement les commits antérieurs. Le pull utilise un fast-forward, sans autostash ni résolution de conflits cachée. Les opérations sont verrouillées dans le dossier commun.

Les tiroirs sont une convention d’écriture d’OKB, **pas des ACL Git**. L’identité du manifeste est déclarée, pas une signature cryptographique. Retirer une note n’efface ni les anciennes copies ni l’historique Git. Après un push réseau échoué, le commit local doit être vérifié avant une reprise manuelle.

## Vérification

Les tests couvrent deux copies Git fictives, exclusions, garde d’aperçu, chemins/symlinks, conservation des changements locaux, staging étranger, commits antérieurs, recherche attribuée et proposition de copie. L’interface ajoute les états de configuration, aperçu, carte, glossaire et packs dans Mémoire, avec les tokens Atelier existants.

Porte d’usage : un mois à deux, cinq réutilisations chacun, aucune fuite et emplacement d’entreprise confirmé. Les tests ne remplacent pas cette porte.
