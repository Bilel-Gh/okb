## Surface

The OKB local web app shell and its daily pages (Aujourd'hui, Cerveau/Notes explorer and reader, Repos, Modules, Suggestions). Mode: Operate. Audience: a developer beside their editor and Claude Code, all day. Job: find a note in seconds, read it, say yes or no to what waits, see how well OKB knows each repository. Constraints: offline, local server, FR/EN, keyboard, 5,000 notes.

## Direction contract

THESIS: A brain is a transit network: subjects are lines, notes are stations, and you always see where you are on the line. Refuses the category default — the near-black dev dashboard of same-size metric tiles with one neon accent (the incumbent look).

OWN-WORLD: Metro signage. A deep navy rail as the shell, cool off-white ground (never cream), white surfaces; the ten note categories become line colours; one reserved signal yellow for the primary action and the « you are here » station; Fira Sans with tabular numerals, Fira Code for code and ids; pill-shaped line badges, station dots, 2px line strokes.

STORY: Open the app, see today: what waits for your yes, where you stopped, what to review. Find any note with ⌘K or the explorer, read it with its line drawn above it, accept a suggestion in one click, watch a repository's knowledge line advance.

FIRST VIEWPORT: Navy rail left (brain switcher, six daily destinations, modules below). Main column: « Aujourd'hui » title, then the waiting queue (suggestions and proposals as rows with Accept / Later), then « Reprendre » (last notes), then the review count; right column: the brain map in small, drawers as lines with stations. Primary action: the yellow Accept on the first waiting row.

FORM: Paris metro map signage, position 3 of 7 on my ordered list (1 library card catalogue, 2 Seyès school notebook, 3 metro map, 4 git diff and commit graph, 5 archive boxes and call numbers, 6 periodic table, 7 IDE theme). Seed key 25e87c45.
